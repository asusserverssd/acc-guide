# Customize Page

**Customize Page** allows you to create and edit custom pages.

![Customize Page list showing an existing custom page and the Add button](../../IMG/8-11_p44-1_custom-page-list.png)

## Adding a blank custom page

1. Click **Add** to open the custom page editor and create a blank custom page.

    ![Add button highlighted on the Customize Page list](../../IMG/8-11_p44-2_custom-page-add.png)

2. Fill in the **Name** and **Description** fields.

    ![Custom page editor with the Name field highlighted](../../IMG/8-11_p45-1_custom-page-name.png)

3. Select the **Role List** option in the **Apply page** field, then select a role from the drop down menu to specify which roles should have access to the custom page (optional).

    ![Custom page editor with the Role List option selected and the role drop-down menu highlighted](../../IMG/8-11_p45-2_custom-page-roles.png)

4. Tick **Enable this page** to enable the custom page.

    ![Enable this page checkbox highlighted in the custom page editor](../../IMG/8-11_p45-3_custom-page-enable.png)

## Editing an existing customized page

Select an existing custom page to open the custom page editor.

![Existing custom page highlighted on the Customize Page list](../../IMG/8-11_p46-1_custom-page-edit.png)

## Using an existing custom page as a template

In the custom page editor, select the **Page List** option in the **Create Type** field, then select a custom page from the drop down list to use as a template.

![Custom page editor with the Page List option selected in the Create Type field and the drop-down list of existing custom pages highlighted](../../IMG/8-11_p46-2_custom-page-template-source.png)

## Loading a custom page template

1. In the custom page editor, click **Template**.

    ![Template button highlighted in the custom page editor toolbar](../../IMG/8-11_p47-1_custom-page-template-button.png)

2. Select a template, then click **Add**.

    ![Template window listing the available templates, with the Add button](../../IMG/8-11_p47-2_custom-page-template-window.png)

## Changing the theme of the custom page

In the custom page editor, click **Styling**, then select a theme from the drop down menu.

![Styling drop-down menu highlighted, showing the available themes](../../IMG/8-11_p47-3_custom-page-theme.png)

## Changing the size of widgets

Click the enlarge or shrink button in the title bar of the widget.

![Enlarge and shrink buttons highlighted in the title bar of a widget](../../IMG/8-11_p48-1_widget-resize.png)

## Adding a widget using the widget gallery

1. In the custom page editor, click **Widget Option**.

    ![Widget Option button highlighted in the custom page editor toolbar](../../IMG/8-11_p48-2_widget-option-button.png)

2. Select a widget from the Widget Gallery, then click **Add**.

    ![Widgets Gallery window listing the available widgets, with the Add button](../../IMG/8-11_p48-3_widget-gallery.png)

## Changing the location of widgets

Drag and drop a widget to the desired location.

![Custom page with a widget highlighted at its new location after being dragged and dropped](../../IMG/8-11_p49-1_widget-move.png)
