# Hardware Inventory Change Log

This page allows you to view the hardware inventory change log.

> **NOTE:** Before using this function, ensure that hardware inventory change notifications and SMTP settings are properly configured. For more information, refer to the **Hardware Asset** section of the **Notification** chapter and the **SMTP Settings** section of the **Options** chapter.

![Hardware Inventory Change Log page with the hardware type tiles, the changed date scatter chart and the change log list](../../IMG/5-2_p35-1_hw-changelog-page.png)

1. Filter the hardware inventory change log by hardware type, date, or keyword.

    ![Hardware Inventory Change Log with the hardware type, date and keyword filters highlighted](../../IMG/5-2_p35-2_hw-changelog-filter.png)

2. Click an entry to view detailed information about the hardware inventory change.

    ![Change log summary pop-up showing the previous and current specification of the changed Processor and Memory components](../../IMG/5-2_p35-3_hw-changelog-summary.png)

    ![Notification email excerpt listing host name P13R, logon user P13R\Administrator and IP address 10.10.30.68, with a table of previous and current specifications for Processor, Memory and FixedDisk](../../IMG/5-2_p35-4_hw-changelog-email.png)
