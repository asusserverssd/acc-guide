# Application Change Log

**Application Change Log** allows you to view application installation information for all managed devices.

> **NOTE:** To export the information of a block click the **Export** button in that block, enter a filename, then click **OK**.

![Application Change Log page with the Top 10 Installed Count chart, the installation date scatter chart and the Installation Log List](../../IMG/5-1_p23-1_change-log-page.png)

## Filtering by application

Click an application in the **Top 10 Installed Count** block to only show devices with the specified application installed.

![Application Change Log with an application selected in the Top 10 Installed Count block and the matching records highlighted](../../IMG/5-1_p23-2_change-log-app-filter.png)

## Filtering by time period

Select a time period using the **Start** and **End** fields to only show records within the specified time period.

![Application Change Log with the Start and End date fields and calendar highlighted](../../IMG/5-1_p24-1_change-log-start-end.png)

Select a time period from the **Period** drop down menu to only show records within the specified time period.

![Application Change Log with the Period drop-down menu open and highlighted](../../IMG/5-1_p24-2_change-log-period.png)

## Filtering by App Type

Select All Apps, Focus, or Untrust to only show records matching the specified app type.

![Application Change Log with the App Type filter highlighted](../../IMG/5-1_p25-1_change-log-app-type.png)

![Application Change Log filtered by App Type showing only matching records](../../IMG/5-1_p25-2_change-log-app-type-result.png)
