# Hardware Sensor

This item allows you to view the details and values for the Voltage / Current, Temperature, Fan, Power Supply, CPU, and Other items. You can view the Hardware Sensor information for the selected device by clicking on the ![Hardware Sensor 箭頭圖示](../../IMG/icon-arrow-circle.png) arrow in the Hardware Sensor block.

![Host Information 的 Hardware Sensor 區塊](../../IMG/2-7_p94-1_host-hwsensor.png)

![Hardware Sensor 清單檢視](../../IMG/2-7_p95-1_host-hwsensor-list.png)

## Quick Buttons

| Icon | Description |
| --- | --- |
| ![清單檢視圖示](../../IMG/icon-list-view.png) | Click to switch the layout to list view. |
| ![圖表檢視圖示](../../IMG/icon-chart-view.png) | Click to view timeline chart of hardware sensor statuses. |
| ![展開此區塊圖示](../../IMG/icon-expand-block_04.png) | Click to expand this block. |
| ![最小化此區塊圖示](../../IMG/icon-minimize-block_04.png) | Click to minimize this block. |

## Toggling the chart view for Hardware sensors

You can toggle the chart view which displays historical data for the Voltage / Current, Temperature, Fan, Power Supply, CPU, and Other sensor events according to different periods of time.

![Hardware Sensor 時間軸圖表](../../IMG/2-7_p96-1_host-hwsensor-chart.png)

### Quick Buttons for timeline chart

| Icon | Description |
| --- | --- |
| ![重新擷取圖示](../../IMG/icon-refetch-small.png) | Click to refetch the device data. |
| ![設定圖示](../../IMG/icon-gear_02.png) | Click to select which data to display on the timeline chart. |
| ![展開此區塊圖示](../../IMG/icon-expand-block_04.png) | Click to expand this block. |
| ![最小化此區塊圖示](../../IMG/icon-minimize-block_04.png) | Click to minimize this block. |

You can customize the timeline chart by selecting the period of time you wish to view for the timeline charts, then selecting the frequency for which the sensor should return data. This will be applied to the timeline charts for all the sensors shown on this page.

![時間區間與頻率選單](../../IMG/2-7_p97-1_host-period.png)

| Period of time | Frequency |
| --- | --- |
| **1D** | 1m, 10m, 20m, 30m, 1h |
| **7D** | 10m, 20m, 30m, 1h, 3h, 6h, 12h |
| **30D** | 30m, 1h, 3h, 6h, 12h, 1d |
| **6M** | 3h, 6h, 12h, 1d, 7d, 14d |
| **1Y** | 6h, 12h, 1d, 7d, 14d, 30d |

Additionally, by clicking on the ![設定圖示](../../IMG/icon-gear_02.png) icon, you can customize the data you wish to view on the timeline

![圖表選項選單](../../IMG/2-7_p98-1_host-chart-menu.png)

| Item | Description |
| --- | --- |
| **Chart Options** | Allows you to check the items you wish to display on the timeline charts such as the **Base line** and **Threshold**. |
| **Data Sampling** | Allows you to select whether the **Maximum** values, **Minimum** values, or **Average** values should be displayed on the timeline chart. |
