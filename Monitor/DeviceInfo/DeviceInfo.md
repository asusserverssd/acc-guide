# Device Information

> **NOTE:** The screenshot may vary between agent and agentless devices, for more details on viewing agentless device details, refer to the **Host Information** section.

The **Device Information** screen gives you various functions to view the status and manage the selected device.

To access the **Device Information** of a managed device, click on the ![清單圖示](../../IMG/icon-list_02.png) icon located next to the managed device you wish to view in the **Devices list**.

![Device Information 畫面](../../IMG/2-2_p26-1_device-info.png)

The **Device Information** screen will display the **OS Information**, **BIOS Version**, **Agent Version**, **Model Name**, **IP Address**, **Timezone**, and **Up Time** of the device.

**Using the search bar and search options**

Refer to the **Search Options** and **Search and Filter Devices** sections of the **Monitor** chapter for more information.

## Device Statuses and Quick Buttons

| Icon | Item | Description |
| --- | --- | --- |
| ![連線狀態圖示](../../IMG/icon-online_01.png) | **Connection status** | This item displays the connection status of the selected managed device. |
| ![訊息狀態圖示](../../IMG/icon-message.png) | **Message status**\* | This item will turn red if the selected device's BMC returns a hardware sensor warning/critical event. |
| ![定位器狀態圖示](../../IMG/icon-locator.png) | **Locator status**\* | This item will turn green if the locator LED is enabled through the ACC Web UI. The locator LED allows you quickly locate the physical location of the device in a server rack. |
| ![Metadata Editor 圖示](../../IMG/icon-tag_01.png) | **Metadata Editor** | This item allows you to edit the metadata of the managed device by double clicking in the **Value** field. |
| ![Remote Desktop 圖示](../../IMG/icon-monitor.png) | **Remote Desktop** | This item allows you to remotely control a managed device. Refer to **Accessing remote desktop** under the **Devices list** section for more details. |
| ![Power Control 圖示](../../IMG/icon-power_01.png) | **Power Control** | This item allows you to power off or restart a managed device. |
| ![Locator LED 圖示](../../IMG/icon-pin.png) | **Locator LED** | This item allows you to turn on/off the Locator LED. |
| ![Refetch 圖示](../../IMG/icon-upload.png) | **Refetch** | This item will refetch the device data. |

\* Only available on BMC enabled devices
