# Software Blocklist

**Software Blocklist** allows you to create or manage rules to prevent selected software applications from running on the managed device during specified time periods.

![Software Blocklist page listing rules with name, block message, update time and status](../../IMG/4-3_p24-1_blocklist-page.png)

## Adding a new software blocklist rule

1. Click ![Add button](../../IMG/icon-add-btn.png) to create a new software blocklist rule.

    ![Software Blocklist Information editor with name, apply software, enable, block time, block message, device rule and scheduler grid](../../IMG/4-3_p24-2_blocklist-editor.png)

2. Enter a **Name** for the software blocklist rule, then use **Apply Software** to select an application from the software list.

    > **NOTE:** For more information on software lists, please refer to the **Software List** section of the **Options** chapter.

3. Tick **Enable** to enable the software blocklist rule.
4. Select **All (7x24)** in the **Block Time** field to enable the software block list rule at all times, or select **Customize Scheduling** to specify a custom schedule using the **Scheduler**.
5. Fill in the **Block Message** field with a brief description that will be displayed on the managed device.
6. Click ![Add Rule button](../../IMG/icon-add-rule-btn.png) to specify which managed devices the software blocklist rule should apply to. To view a list of managed devices that will be affected by the software blocklist rule, click ![Preview button](../../IMG/icon-preview-btn.png).
7. Click ![Add button with save icon](../../IMG/icon-save-add-btn.png) to save the software blocklist rule.

## Editing a software blocklist rule

1. Double click an existing rule from the Software Blocklist rule list to open the rule editor.

    ![Software Blocklist Information editor for an existing rule with the Cancel, Delete and Save buttons](../../IMG/4-3_p25-1_blocklist-edit.png)

2. After making the desired changes, click ![Save button](../../IMG/icon-save-btn.png) to save the software blocklist rule.

## Deleting a software blocklist rule

1. Click an existing rule from the Software Blocklist rule list to open the rule editor.
2. Click ![Delete button](../../IMG/icon-delete-btn.png) to delete the software blocklist rule.
